# Druporia

Full-stack portfolio and marketplace platform built with Next.js 14 (App Router).

Live site: https://druporia-soft.vercel.app

## Tech Stack

Next.js 14 (App Router), Prisma ORM, Clerk for authentication and role-based access control, and a Tawk.to live chat widget.

## Features

Portfolio showcase, marketplace listings with image upload support, an admin panel for editing site content, a contact form, and a team profiles page.

## Getting Started

Install dependencies with npm install, generate the Prisma client with npx prisma generate, then start the dev server with npm run dev. The app runs at http://localhost:3000 by default. Configure environment variables for the database connection, Clerk keys, and Tawk.to widget ID before running locally.
